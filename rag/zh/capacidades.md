# 智能体功能

该智能体使用自然语言（葡萄牙语、英语或中文）回答关于已配置业务领域数据的问题（详见 `config/`
目录下的配置包——名称、schema 和业务规则都来自那里）。它只读取数据，绝不会修改所查询的数据库。

## 简单的架构

| 层级 | 职责 |
|--------|-----------------|
| `dominio.md`（config/） | **唯一的分析技能** —— 描述该业务领域的 schema 和规则；查询直接发往已配置的数据库，根据业务领域使用 SQL 或 GraphQL |

## 智能体如何回答数据问题

```text
用户提出问题
      ↓
编排器 → consultar_analista()
      ↓
分析子代理（已加载 dominio.md 技能）
      ↓
查询已配置的数据库（根据业务领域使用 SQL 或 GraphQL）
      ↓
用 pandas 处理结果
      ↓
以表格和/或图表形式回答
```

## 支持的分析类型

**聚合：** 按 schema 中任意维度计算的总计、平均值、计数

**排名：** 按任意指标排出前 N 名

**对比：** 跨时间段、类别或分组的比较

**交叉分析：** 通过 dominio.md 中描述的关联键组合多张表（SQL 业务领域用 JOIN；GraphQL
业务领域则每次查询关联一层，再在 pandas 中做交叉）

**概念解释：** 关于该业务领域指标含义和业务规则的问题

## 输出格式

- Markdown 表格
- 图表（柱状图、折线图、饼图、散点图等）
- 包含分析和图表的 PDF
- 可下载的 Excel 表格
- 仪表盘上的持久化自定义面板

没有明确要求图表时，数据类回答以表格呈现（结果只有一个值时则为文字）。需要可视化请说"图表"，
两者都要请说"图表和表格"。

## 支持的自然语言时间段

"今天"、"昨天"、"本周"、"上周"、"最近N天/周/个月"、"本月"、"上个月"、"今年"、"去年"、
"本季度"、"上一季度"、"全部时间"、某个具体月份（例如"2026年5月"）和明确的日期范围
（例如"从2026年5月1日到5月31日"）——此外还包括配置包中定义的该业务领域特有的时间段
（例如业务自有的财政季度和财政年度、自有的时间段标签）。

## 回答之后

可以要求调整（"同样的图表，但用灰色"、"只要前5名"），也可以询问已生成的图表（"这里为什么有个
峰值？"）——智能体能够查看图片。每个数据类回答都带有一个**分析参数**块，列出实际使用的时间段和
筛选条件，并标明哪些是默认假设的。

## 仪表盘

仪表盘是一个面板网格（图表在每次刷新时重新计算）：

- **默认面板** —— 随业务领域的配置包提供，不能删除
- **自定义面板** —— 智能体按要求创建、编辑和删除，例如"在仪表盘上添加一个按<维度>展示<指标>的
  面板，时间范围为最近30天"（固定之前它会先确认）

图表类型：柱状图、折线图、饼图、环形图、雷达图、极坐标面积图、散点图、气泡图和热力图。面板可以
拖动重新排序，自定义面板的所有者可以通过面板自带的按钮将其共享给其他用户。

关于屏幕的提问：智能体能看到列出的提醒、产出文件和任务，并能分析你附加到聊天中的屏幕截图
（"选择屏幕区域"按钮，最多3张图片）。

## 对话

- **语音：** 录制音频，试听后丢弃或发送；音频会被转写，转写文本将作为你的消息发出
- **停止：** "停止回复"按钮可中断正在进行的回复
- **对话记录：** 每位用户可以有多个对话，之后可继续
- **语言：** 智能体使用界面中选择的语言回复（葡萄牙语、英语或中文）

## 定时任务

智能体可以创建自动运行的任务。创建时，它会查询真实数据、编写任务代码、测试通过后才保存（测试失败
会尝试修复；如果修复不了，则不会创建该任务）。此后，任务会按时运行，无需智能体参与——结果由代码
直接根据数据计算得出（唯一的例外是按要求撰写的文字分析）。

**周期性报告：**

- "每周一早上8点生成<指标>的汇总"
- "每天早上7点生成一份包含<分析>的PDF"
- "每月第一天把数据导出为Excel"
- "每周生成一份带分析和洞察的报告" —— 代码计算数字，AI 撰写解读，并会对照这些数字进行核对

结果（PDF、图表、Excel）会显示在**产出文件**面板中。系统不会自行发送邮件。

**阈值监控：**

- "如果<指标>超过<N>就通知我" —— 简单条件（一个指标、一次比较）
- "当<指标A> > <X> 且 <指标B> < <Y> 时提醒我" —— 复合条件（与/或，多个指标或对象）

提醒会出现在仪表盘的**提醒**铃铛中。条件从"未满足"变为"满足"时才发出提醒——不会在每次检查时
重复——条件不再成立后会重新生效。未指定频率时，监控每5分钟检查一次（默认最小间隔：5分钟）。
创建监控时，智能体会展示**我对该请求的理解**（条件、频率、数据时间窗口、所选指标和聚合方式），
方便你纠正与预期不符的地方。

支持的频率：`once`、`daily`、`weekly`、`monthly`、`every_Xm`、`every_Xh`、`every_Xd`

**管理操作：** "列出任务"、"暂停任务 003"、"恢复任务 003"、"删除任务 001"、"编辑任务 003：把阈值
改为50"（智能体会修改代码、测试并保存，同时保留旧版本）。在**任务**面板中还可以立即运行（▶）、
开关通知（监控除外，监控始终通知）、查看代码和运行历史，以及通过聊天编辑。

## 限制

- 只读取数据：不会修改业务领域的数据库
- 不会编造数据：如果所要求的筛选条件没有真实数据，智能体会如实说明（并可能展示最接近的结果，
  同时明确指出它与所问内容不同）
- 过大的结果会被概括而不是完整展示——可以要求前 N 名或聚合
- 不会自行发送邮件

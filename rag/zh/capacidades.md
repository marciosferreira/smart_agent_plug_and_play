# 智能体功能

该智能体使用自然语言回答关于已配置数据库中数据的问题（详见 `config/` 目录下的
配置包——名称、schema 和业务规则都来自那里）。

## 简单的架构

| 层级 | 职责 |
|--------|-----------------|
| `dominio.md`（config/） | **唯一的分析技能** —— 所有数据问题都直接对已配置数据库执行 SQL |

## 智能体如何回答数据问题

```
用户提出问题
      ↓
编排器 → consultar_analista()
      ↓
子代理读取 dominio.md（配置包）
      ↓
编写并执行针对已配置数据库的 SQL
      ↓
用 pandas 处理结果
      ↓
以表格或图表形式回答
```

## 支持的分析类型

**聚合：** 按 schema 中任意维度计算的总计、平均值、计数

**排名：** 按任意指标排出前 N 名

**对比：** 跨时间段、类别或分组的比较

**交叉分析：** 任意表之间通过 JOIN 的组合（关联键详见 dominio.md）

**概念解释：** 关于该业务领域指标含义和业务规则的问题

## 输出格式

- Markdown 表格
- 图表（柱状图、折线图、饼图、散点图）
- 包含分析和图表的 PDF
- 可下载的 Excel 表格
- 仪表盘上的持久化自定义面板

## 支持的自然语言时间段

"今天"、"昨天"、"本周"、"最近N天"、"本月"、"上个月"、明确的日期
（例如"从5月1日到5月28日"）——此外还包括配置包中定义的该业务领域特有的
时间段（例如财政季度、业务自有的时间段标签）。

## 定时任务

智能体可以创建自动运行的任务。

**周期性报告：**

- "每周一早上8点给我发送<指标>的汇总"
- "每天早上7点生成一份包含<分析>的PDF"
- "每月第一天把数据导出为Excel"

**阈值监控：**

- "如果<指标>超过<N>就通知我"
- "当<条件>发生时提醒我"

支持的频率：`once`、`daily`、`weekly`、`monthly`、`every_Xm`、`every_Xh`、`every_Xd`

**管理操作：** "列出任务"、"暂停任务 003"、"删除任务 001"
